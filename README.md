# Welcome
 
This is my project, an anime and manga news site that will be updated as Crunchyroll publishes new posts on its RSS Feed [Crunchyroll News](https://www.crunchyroll.com/pt-br/news/about#rssx) which will be in XML format. Using Python's feedparser to format and filter the required data.

For more development information see [```README-develop```](https://github.com/olavodotpy/AnimeNews/blob/Master/README-develop.md).
