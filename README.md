## FeedRSS

Usando o RSS da [Crunchyroll](https://www.crunchyroll.com/pt-br/news/about#rssx) que vai estar em formatado XML. Usando o feedparser do python para formatar e filtrar os dados necessários para o uso no blog.


Para mais informações para desenvolvimento consulte a branch [develop](https://github.com/olavodotpy/AnimeNews/tree/develop)
