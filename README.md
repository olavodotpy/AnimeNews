# welcome

Esse é o meu site de notícias de animes e mangas que vai se atualizando a medida que a Crunchyroll vai lançando novos posts no seu FeedRSS da [Crunchyroll Notícas](https://www.crunchyroll.com/pt-br/news/about#rssx) que vai estar em formatado XML. Usando o feedparser do python para formatar e filtrar os dados necessários.

Para mais informações de desenvolvimento e clone consulte a branch [develop](https://github.com/olavodotpy/AnimeNews/tree/develop) e o Markdown ```README-develop```
