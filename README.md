# Welcome
 
 Esse é o meu projeto, um site de notícias de animes e mangas que vai se atualizando à medida que a Crunchyroll vai publicando novos posts no seu FeedRSS da [Crunchyroll Notícas](https://www.crunchyroll.com/pt-br/news/about#rssx) que vai estar em formatado XML. Usando o feedparser do python para formatar e filtrar os dados necessários.
 
 Para mais informações de desenvolvimento consulte [```README-develop```](https://github.com/olavodotpy/AnimeNews/blob/Master/README-develop.md).
